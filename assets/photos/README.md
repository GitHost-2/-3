# Fotos del tornado

Pon aquí **4 fotos** (`.jpg`, `.png` o `.webp`, con el nombre que quieras). Se usan las 4 primeras por orden
alfabético, por eso conviene llamarlas `foto1.jpg`, `foto2.jpg`, `foto3.jpg` y `foto4.jpg`.

Luego ejecuta `npm install` (una vez) y `npm run build`. El build las reduce (máx. 900×1200) y las incrusta
en la página, así no hace falta subir nada más. Si faltan fotos, esas cartas se muestran con un corazón y
el texto «Tu foto aquí».
